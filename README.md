This program writes a single original one-line joke about office life to `/output/entry.txt`. The joke's premise is a meeting skipped to do the work for that meeting, and the punishment for skipping it: another meeting, booked to ask why it was skipped — the bureaucracy loop closes on itself, and the laugh lands in the last few words.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
